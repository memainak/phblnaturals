# Dr. Trinath's PHBL Naturals storefront

## Run it
Open `index.html` in a modern browser. No build tools are required.

## Included
- Responsive header and footer using the green/lime/cream brand palette
- Three-slide automatic hero slider with manual controls
- 15 sample products with category filters, search, sorting, and detail modal
- Cart with quantity controls and localStorage persistence
- Demo checkout and newsletter form
- Responsive mobile navigation

## Before going live
The 15 products, prices, descriptions, ingredient copy and product images are sample/demo content. Replace them with verified PHBL Naturals catalogue details and approved product photography. Product images currently load from Unsplash and require an internet connection. The cart/checkout are front-end demonstrations only; connect a backend, inventory, shipping, and a payment gateway before accepting real orders. Update social links and policies with the business's official details.
